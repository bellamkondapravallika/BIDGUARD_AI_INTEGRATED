# 90-second judge demo

1. Login with any non-empty email/password.
2. Dashboard: show compliance KPI cards.
3. Create a bid case.
4. Upload 4–6 sample documents.
5. Run AI analysis.
6. Open Compliance Matrix.
7. Open a red/amber exception and show evidence.
8. Open Risk Intelligence.
9. Finish with Audit Trail and Report.

The backend also exposes `/api/v1/demo/inconsistent-bidder`, which returns a seeded high-risk mock bidder with evidence-backed adapter results.
